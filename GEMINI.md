# Gemini Workflow

Use Gemini for broad repository scans, large log compression, and boilerplate generation.

Default model: `gemini-3-flash-preview`

Suggested prompts:

- Analyze the repository and summarize the architecture.
- Compress this error log into the root cause and likely fix.
- Generate the repetitive test scaffolding for this module.

Keep final implementation and verification local in Codex.
