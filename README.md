# MajdaMatcha Launch Kit

MajdaMatcha is a premium matcha coffee shop concept for Saudi Arabia. This workspace contains the brand system, market-backed business plan, menu, social launch kit, and a working website.

## Run The Website

```bash
npm install
npm run dev
```

## Deliverables

- Website: `src/` and `public/assets/`
- Launch overview: `docs/launch-kit/majdamatcha-launch-overview.md`
- Brand and menu: `docs/brand/brand-menu-system.md`
- Saudi market and business plan: `docs/research/saudi-market-business-plan.md`
- Social media launch kit: `docs/social/social-launch-kit.md`

The website hero adapts the product-forward structure of royalbev.com: giant stacked brand type, central beverage imagery, airy backdrop, and smooth motion cues.
